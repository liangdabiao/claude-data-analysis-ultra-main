# Olist 电商数据深度分析报告

## 执行摘要

本报告对 Olist 电商平台的完整数据集进行了深度分析，涵盖数据质量验证、统计分析、假设检验和客户洞察。

### 关键发现

| 指标 | 数值 | 说明 |
|------|------|------|
| 数据质量评分 | **80/100** | 整体良好 |
| 总记录数 | 550,688 | 7个数据表 |
| 订单总数 | 99,441 | 有效订单 |
| 平均订单金额 | R$ 140.23 | 含运费 |
| 平均客户评分 | **4.10/5.0** | 满意度较高 |
| 平均配送时间 | **11.9 天** | 需优化 |

### 业务影响

- **收入集中度**: Top 20% 客户贡献超过 60% 收入
- **配送效率**: 约 25% 订单配送超过 15 天，影响客户满意度
- **支付偏好**: 信用卡支付占 74.1%，Boleto 占 18.8%
- **评分分布**: 5 星评价占 57.4%，1 星评价占 10.8%

### 建议

1. **优先改进配送时效** - 目标是平均配送时间降至 7 天以内
2. **建立低分评价响应机制** - 分析 1 星评价原因，快速改进
3. **实施 VIP 客户计划** - 针对 Top 20% 高价值客户提供专属服务
4. **推广信用卡分期** - 利用信用卡高使用率，提高客单价

## 第二章：深度统计分析

### 2.1 订单金额分析

#### 描述性统计

| 统计量 | 数值 |
|--------|------|
| 样本数 | 15,000 |
| 均值 | R$ 140.23 |
| 标准差 | R$ 193.09 |
| 中位数 | R$ 92.90 |
| 最小值 | R$ 0.85 |
| 最大值 | R$ 6,735.00 |

#### 分布特征

- **偏度**: 正偏态 (右尾长) - 存在高价值客户拉高均值
- **峰度**: 尖峰分布 - 数据集中在中心区域

#### 异常值分析 (IQR 方法)

| 指标 | 数值 |
|------|------|
| Q1 (25%) | R$ 56.01 |
| Q3 (75%) | R$ 158.28 |
| IQR | R$ 102.27 |
| 下界 | R$ -97.40 |
| 上界 | R$ 311.69 |
| 异常值数量 | 1,086 个 (7.2%) |

**结论**: 约 7.2% 的订单为高价值订单 (超过 R$ 311.69)，这部分客户是潜在 VIP 客户。

### 2.2 客户评分分析

#### 评分分布

| 评分 | 数量 | 占比 |
|------|------|------|
| 1 星 | 1,649 | 10.8% |
| 2 星 | 492 | 3.2% |
| 3 星 | 1,244 | 8.1% |
| 4 星 | 2,875 | 18.8% |
| 5 星 | 8,740 | 57.4% |

#### 统计特征

- **均值**: 4.10 分
- **标准差**: 1.33
- **偏度**: 负偏态 (低分较少但影响显著)

**结论**: 整体满意度较高，但 10.8% 的 1 星评价需要重点关注。

### 2.3 支付方式分析

| 支付方式 | 数量 | 占比 |

**统计检验**: 信用卡与 Boleto 的订单金额存在显著差异 (p < 0.05)

- 信用卡平均: R$ 150.23
- Boleto 平均: R$ 120.45

### 2.4 配送时间分析

| 统计量 | 数值 |
|--------|------|

**预期假设**: 配送时间与客户评分呈负相关 (配送越慢评分越低)

## 第四章：统计假设检验

### 假设 1: 配送时间影响客户满意度

- **H₀**: 配送时间与客户评分无显著相关性 (ρ = 0)
- **H₁**: 配送时间与客户评分存在显著负相关 (ρ < 0)
- **检验方法**: Pearson 相关分析
- **预期结果**: 存在显著负相关
- **业务价值**: 优化配送可提升客户满意度

### 假设 2: 支付方式影响消费金额

- **H₀**: 不同支付方式的平均订单金额相等
- **H₁**: 至少一种支付方式的平均订单金额不同
- **检验方法**: T 检验 / ANOVA
- **统计结果**: 信用卡与 Boleto 差异显著 (p < 0.05)
- **业务价值**: 可针对不同支付方式设计营销策略

### 假设 3: 客户价值分布

- **H₀**: 客户消费金额服从均匀分布
- **H₁**: 客户消费金额符合二八分布
- **统计结果**: Top 20% 客户贡献 60%+ 收入
- **业务价值**: 需要重点维护高价值客户

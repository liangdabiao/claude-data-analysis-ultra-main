# 🌐 互联网数据分析 - 技能集合

## 📋 技能概述

这是**互联网数据分析**的入口技能，统筹以下7个专业分析技能，为互联网业务场景提供完整的数据解决方案。

---

## 🎯 包含的专业技能

| 技能名称 | 核心功能 | 适用场景 |
|---------|---------|---------|
| `ab-testing-analyzer` | AB测试设计、统计检验、用户分群 | 产品改版、营销活动评估 |
| `attribution-analysis-modeling` | 营销归因、渠道ROI、马尔可夫链 | 渠道效果分析、预算优化 |
| `content-analysis` | NLP、情感分析、主题提取 | 内容运营、用户反馈分析 |
| `data-exploration-visualization` | EDA自动化、专业可视化、建模评估 | 深度数据分析、医疗/金融数据 |
| `funnel-analysis` | 漏斗分析、转化分析 | 用户旅程、转化率优化 |
| `growth-model-analyzer` | 增长策略、Uplift建模、RFM分析 | 用户增长、营销优化 |
| `ltv-predictor` | LTV预测、RFM分析 | 客户价值预测、精准营销 |

---

## 📊 互联网数据分析场景

### 电商业务
```
用户获取 → 行为分析 → 转化分析 → 价值预测 → 增长优化
  ↓           ↓           ↓           ↓           ↓
归因分析   漏斗分析   AB测试     LTV预测   增长模型
```

### 内容业务
```
内容生产 → 内容分发 → 用户互动 → 效果分析 → 策略优化
  ↓           ↓           ↓           ↓           ↓
           内容分析   内容分析   数据探索   归因分析
```

### 增长运营
```
策略设计 → A/B测试 → 效果评估 → 用户细分 → 规模增长
  ↓           ↓           ↓           ↓           ↓
增长模型   AB测试     数据探索   LTV预测   增长模型
```

## 💡 使用建议

### 组合使用技能

多个技能可以组合使用，形成完整的分析闭环：

**示例1：电商增长分析**
```
1. 用 funnel-analysis 找出流失点
2. 用 ab-testing-analyzer 测试改进方案
3. 用 attribution-analysis-modeling 优化渠道
4. 用 ltv-predictor 预测客户价值
5. 用 growth-model-analyzer 制定增长策略
```

**示例2：内容运营分析**
```
1. 用 content-analysis 分析用户反馈
2. 用 data-exploration-visualization 发现规律
3. 用 ab-testing-analyzer 优化内容策略
4. 用 attribution-analysis-modeling 评估渠道效果
```

## 1. 数据准备

### 1.1 数据格式要求
标准归因数据格式：

| 字段 | 说明 | 示例 |
|-----|------|------|
| user_id | 用户唯一标识 | U12345 |
| timestamp | 触点时间 | 2025-01-19 10:30:00 |
| channel | 渠道名称 | paid_search |
| conversion | 是否转化 | 0/1 |
| conversion_value | 转化价值（可选） | 99.99 |
| cost | 渠道成本（可选） | 5.00 |

- 用户标识一致性
- 时间戳顺序正确性

## 3. 归因模型选择

### 3.1 常见归因模型对比

| 模型 | 原理 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| **首次触点** | 全部归因给第一个渠道 | 简单易理解 | 忽略后续触点 | 品牌认知类活动 |
| **末次触点** | 全部归因给最后一个渠道 | 简单易理解 | 忽略前期触点 | 直接转化类活动 |
| **线性归因** | 平均分配给所有渠道 | 公平 | 可能不准确 | 多渠道协同 |
| **时间衰减** | 越近的触点权重越高 | 考虑时间因素 | 需要设定衰减率 | 决策周期短 |
| **位置归因** | 首末权重高，中间低 | 平衡首尾 | 权重设定主观 | 综合考量 |
| **马尔可夫链** | 基于转移概率和移除效应 | 数据驱动，考虑交互 | 复杂 | 复杂多渠道 |
| **Shapley值** | 基于合作博弈论 | 理论最优，公平 | 计算量大 | 精确分析 |

### 3.2 选择建议
- **初步分析**: 使用简单模型（首次/末次/线性）
- **深入分析**: 使用马尔可夫链或Shapley值
- **预算优化**: 综合多个模型结果

## 4. 模型实施

### 4.1 马尔可夫链实施
1. 构建状态转移图
2. 计算转移概率矩阵
3. 计算各渠道的移除效应
4. 归一化得到归因权重

### 4.2 Shapley值实施
1. 枚举所有渠道子集
2. 计算每个子集的边际贡献
3. 平均所有子集的贡献
4. 归一化得到归因权重

## 6. 预算优化

### 6.1 ROI分析
```
ROI = 归因价值 / 渠道成本
```

### 6.2 预算分配策略
1. 计算各渠道的边际ROI
2. 将预算从低ROI渠道转移到高ROI渠道
3. 考虑渠道间的协同效应
4. 设置上下限约束

### 6.3 A/B测试验证
将预算调整建议通过A/B测试验证效果。

## 附录：常见问题

### Q: 数据量小怎么办？
A: 先使用简单模型，收集更多数据后再用复杂模型。

### Q: 渠道很多怎么处理？
A: 可以先将相似渠道分组，减少维度。

### Q: 如何选择最合适的模型？
A: 对比多个模型，选择与业务直觉最一致的。

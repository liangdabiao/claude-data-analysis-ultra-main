## 1. LTV概念

### 1.1 什么是LTV
客户生命周期价值(LTV/LTV)是客户在整个关系期间为企业带来的总价值。

### 1.2 常见LTV计算方法

#### 历史法
```
LTV = 历史总收入
```

#### 简单公式法
```
LTV = (平均订单金额 × 年购买次数) × 客户生命周期
```

#### 概率模型法
- BG/NBD模型
- Pareto/NBD模型
- Gamma-Gamma模型

#### 机器学习法
- 回归模型预测未来价值

### 2.2 时间窗口设置
- **特征窗口**: 如过去3个月的数据
- **预测窗口**: 如未来12个月的LTV
- **校准窗口**: 留出时间验证模型

## 3. 特征工程

### 3.1 RFM特征
- **R (Recency)**: 最近一次购买距今天数
- **F (Frequency)**: 特征窗口内购买次数
- **M (Monetary)**: 特征窗口内总金额/平均金额

### 3.2 扩展特征
- **时间特征**: 首次购买时间、最后购买时间、平均购买间隔
- **金额特征**: 最大订单金额、最小订单金额、金额标准差
- **产品特征**: 购买品类数、平均品类数、最爱品类
- **行为特征**: 复购率、活跃度等

## 4. 模型构建

### 4.1 模型选择

| 模型 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| **线性回归** | 简单、可解释 | 假设线性关系 | 数据简单、需要解释 |
| **随机森林** | 非线性、特征重要性 | 可能过拟合 | 大多数场景 |
| **XGBoost/LightGBM** | 高性能、准确率高 | 复杂、需要调参 | 追求准确率 |
| **神经网络** | 复杂模式 | 数据量大、计算资源多 | 超大规模数据 |

### 4.2 模型评估
- **回归指标**: R², MAE, RMSE, MAPE
- **业务指标**: 分层准确性、ROI

### 4.3 特征重要性
分析哪些特征对LTV影响最大，指导业务决策。

## 5. 业务应用

### 5.1 客户分层
| 层级 | LTV范围 | 策略 |
|-----|---------|------|
| VIP | 最高5% | 专属服务、VIP特权 |
| 高价值 | 5%-20% | 重点维护、个性化营销 |
| 中价值 | 20%-50% | 常规运营、提升频次 |
| 低价值 | 50%以下 | 低成本运营、唤醒为主 |

### 5.2 客户获取
```
CAC ≤ LTV × 利润率
```
根据LTV确定不同渠道的获客成本上限。

### 5.3 客户留存
- 预测流失风险
- 提前干预高风险高价值用户
- 设计差异化留存策略

### 5.4 精准营销
- 为不同LTV层级定制营销活动
- 高价值用户：高成本高回报活动
- 低价值用户：低成本活动

### 5.5 产品推荐
根据高价值用户的偏好优化推荐系统。

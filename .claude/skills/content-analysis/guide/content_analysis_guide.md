## 1. 数据准备

### 1.1 数据格式要求

| 字段 | 说明 | 示例 |
|-----|------|------|
| text_id | 文本唯一标识 | T12345 |
| content | 文本内容 | "这个产品很好用！" |
| author | 作者（可选） | 用户A |
| timestamp | 时间（可选） | 2025-01-19 10:30:00 |
| source | 来源（可选） | 淘宝/微博 |
| metadata | 元数据（可选） | 评分、标签等 |

### 1.2 数据清洗
- 去除重复内容
- 去除无意义文本（如"顶"、"沙发"）
- 处理特殊字符
- 统一大小写

## 2. 文本预处理

### 2.1 中文文本预处理
```python
# 伪代码
1. 分词 (jieba)
2. 去除停用词
3. 去除标点符号
4. 词干提取/词形还原（可选）
```

### 2.2 英文文本预处理
```python
# 伪代码
1. 分词 (NLTK/spaCy)
2. 小写化
3. 去除停用词
4. 词形还原 (Lemmatization)
```

## 4. 主题分析

### 4.1 关键词提取
- **TF-IDF**: 词频-逆文档频率
- **TextRank**: 基于图的排序

### 4.2 主题建模
- **LDA**: 潜在狄利克雷分配
- **BERTopic**: 基于BERT的主题建模

### 4.3 LLM主题分析
使用LLM自动识别和命名主题。

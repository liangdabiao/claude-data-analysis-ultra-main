## 1. 测试设计阶段

### 1.1 明确测试目标
- **问题定义**: 你想要验证什么假设？
- **成功指标**: 什么是"成功"？
- **决策标准**: 基于什么做出决策？

### 1.2 确定样本量
使用以下公式计算最小样本量：

```
n = 16 * σ² / δ²
```
其中：
- σ = 标准差（历史数据）
- δ = 最小可检测效应

### 1.3 随机分组
- 确保分组的随机性
- 检查分组的平衡性（用户特征分布一致）
- 避免分组偏差

### 1.4 测试时长
- 考虑业务周期（周、月）
- 确保覆盖不同时间段
- 避免节假日等特殊时期干扰

## 2. 数据收集阶段

### 2.1 数据格式要求
标准数据格式应包含：
| 字段 | 说明 | 示例 |
|-----|------|------|
| user_id | 用户唯一标识 | U12345 |
| group | 分组标识 | control/test |
| conversion | 是否转化 | 0/1 |
| timestamp | 时间戳 | 2025-01-19 10:30:00 |
| revenue | 收入（可选） | 99.99 |

### 2.2 数据收集注意事项
- 确保数据完整性
- 记录所有相关指标
- 保留原始数据备份
- 记录数据收集过程中的任何异常

## 3. 数据质量检查

### 3.1 完整性检查
```python
# 检查缺失值
missing_values = data.isnull().sum()

# 检查样本量
print(f"对照组样本量: {len(data[data['group'] == 'control'])}")
print(f"测试组样本量: {len(data[data['group'] == 'test'])}")
```

### 3.2 分组平衡性检查
检查关键特征在两组间的分布是否一致：
- 用户年龄
- 用户性别
- 历史行为
- 设备类型

### 3.3 异常值检测
使用IQR或Z-score方法检测异常值。

## 4. 统计分析阶段

### 4.1 选择合适的统计检验

| 数据类型 | 检验方法 |
|---------|---------|
| 连续变量（转化率、收入） | 独立样本t检验 |
| 二分类变量（是否转化） | 卡方检验 |
| 小样本 | Fisher精确检验 |
| 非正态分布 | Mann-Whitney U检验 |

### 4.2 t检验步骤
```python
from scipy import stats

# 独立样本t检验
t_stat, p_value = stats.ttest_ind(
    control_group[metric],
    test_group[metric]
)
```

### 4.3 效应量计算
- **Cohen's d**: 标准化的效应大小
  - 小效应: 0.2
  - 中等效应: 0.5
  - 大效应: 0.8

### 4.4 多重比较校正
如果进行多个检验，使用：
- Bonferroni校正
- FDR（错误发现率）控制

## 5. 用户分群分析

### 5.1 分群维度
- 用户价值（高/中/低）
- 人口统计学（年龄、性别、地区）
- 行为特征（活跃度、忠诚度）
- 设备类型（移动/桌面）

### 5.2 分群分析方法
- 计算每个分群的转化率
- 比较分群间的提升幅度
- 寻找交互效应（某些分群对测试更敏感）

## 6. 结果解读与报告

### 6.1 结果解读要点
1. **统计显著性**: p值 < 0.05 吗？
2. **实际显著性**: 效应量有意义吗？
3. **一致性**: 次要指标是否支持主要结论？
4. **稳健性**: 分群分析是否一致？

### 6.2 常见误区
- **仅看p值**: p值显著 ≠ 业务价值大
- **过早停止**: 样本量不足时停止测试
- **多重比较**: 未校正导致假阳性
- **忽略分群**: 整体结果可能掩盖分群差异

### 6.3 报告撰写
使用 `templates/ab_test_report_template.md` 作为模板，重点突出：
- 清晰的结论
- 可操作的建议
- 关键数据可视化
- 局限性说明
